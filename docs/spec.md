## 2. 世界観・ストーリー（決定）

前作スロット（ASO摩天楼）のエピソードBIG 第10話の続きにします。

- 摩天楼の財宝で借金を返したはずが、打ち上げで散財して、また借金ができてしまった
- 「どうしよう。こおり生きていけないよ～～！！」と困っていると、ふるカワが「**ダンジョン探検隊**」の話を持ってくる
- 町の近くに、不思議なダンジョンがいくつも現れた。依頼をこなすとお金がもらえる
- こおりくんは、見張りでついてくるおにおにと一緒に探検隊「**ばりきつよめ**」を作り、依頼をこなして借金を返していく
- 主人公をおにおににしたときは、おにおにが「貸した金は自分で取り返す」と、こおりくんを連れてダンジョンへ行く（案）。借金はどちらでも同じ（こおりくんがおにおにに返す）で、話の流れも同じ。セリフが少し変わるだけ
- ダンジョンには、ライバルの探検隊（5DX・ASK-3・お願いマッスル）や、摩天楼から逃げ出した敵がいる。いちばん奥では、また何かがよみがえろうとしている……

### 目標（案）

- **借金の残り**が画面に出ていて、依頼の報酬で減っていく
- 借金を返し切ると **エンディング**。そのあとも遊べる（もっと深いダンジョンが出る）

## 3. ゲームの流れ（案）

```
タイトル → 町（拠点） → 依頼を受ける → ダンジョン → 帰還 → 報酬・借金返済 → 町 …
```

1. **町**で依頼を受け、道具を準備し、連れていく仲間を選ぶ
2. **ダンジョン**を 1 階ずつ降りる。目的の階で依頼をこなす（人を助ける・道具を拾う・敵を倒す）か、最下階まで行く
3. 依頼を達成すると、その場で町に戻るか、先へ進むか選べる
4. **倒れたら**町に戻される（10章）
5. 町で報酬を受け取り、おにおにに借金を返す

## 4. ダンジョンのしくみ（案）

### 4.1 マップ

- 1 階は 横 56 × 縦 32 マス くらい。部屋 4〜8 個を通路でつなぐ
- 見えるのは画面の真ん中あたり。部屋に入ると部屋全体が見え、通路では周り 1 マスだけ見える
- 一度通った場所は **ミニマップ** に残る
- 各階に **階段** が 1 つ。乗ると「降りますか？」と聞く

### 4.2 マスの種類

| マス | 内容 |
|---|---|
| 床・通路 | 歩ける |
| 壁 | 歩けない |
| 水・溶岩 | ダンジョンによって置く。こおりくんは溶岩に入るとダメージ（案） |
| 階段 | 次の階へ |
| ワナ | 踏むと見える。くわしくは 4.4 |

### 4.3 ひとつの階の決まりごと

- 一つの階に長くいると風が吹き、最後は追い出される（ポケダンと同じ。案：800 ターンで警告、1000 ターンで追い出し）
- まれに **モンスターハウス**（部屋に敵がたくさん）
- 敵は時間がたつと少しずつ増える

### 4.4 ワナ（案）

| ワナ | 効果 |
|---|---|
| トゲのワナ | ダメージ |
| ワープのワナ | 同じ階のどこかへ飛ぶ |
| 大腸炎のワナ | おなかが急に減る（ドタバタ枠） |
| ねむりのワナ | 数ターン動けない |
| 落とし穴 | 次の階へ落ちる（ダメージ少し） |
| 借金取りのワナ | お金が少し減る。おにおにが「金返せ！」 |

## 5. ターンと行動（案）

- こおりくんの行動：移動（8 方向）、攻撃（正面）、わざ、道具、足踏み、向きを変える
- 移動・攻撃・道具などをすると 1 ターン進む。仲間と敵がそのあと動く
- **すばやさ**：速い敵は 1 ターンに 2 回動く（「はやい」状態も同じ）
- 斜め移動は、角を壁がふさいでいたらできない
- ボタン長押しで **ダッシュ**（分かれ道や敵が見えたら止まる）

## 6. キャラの能力（案）

| 能力 | 内容 |
|---|---|
| Lv | 1〜99 |
| HP | 0 で倒れる。歩くと少しずつ回復 |
| こうげき / ぼうぎょ | ふつうの攻撃・物理わざ |
| とくこう / とくぼう | 特殊わざ |
| すばやさ | 段階（ふつう・はやい・おそい） |
| 満腹度 | 100 から歩くたびに減る。0 になると HP が減っていく |
| けいけんち | 敵を倒すとたまり、Lv が上がる |

### 6.1 属性（決定：7つ。相性は案）

属性は こおり・ほのお・みず・しぜん・かぜ・ふしぎ・ふつう の 7 つ（決定）。

相性（案）：行がわざの属性、列が受ける側の属性。◎ = 1.5 倍、△ = 0.67 倍、空欄 = 1 倍

| わざ＼受ける | こおり | ほのお | みず | しぜん | かぜ | ふしぎ | ふつう |
|---|---|---|---|---|---|---|---|
| こおり | | △ | | ◎ | ◎ | | |
| ほのお | ◎ | | △ | ◎ | | | |
| みず | | ◎ | | △ | | | |
| しぜん | | △ | ◎ | | △ | | |
| かぜ | △ | | | ◎ | | | |
| ふしぎ | | | | | | ◎ | △ |
| ふつう | | | | | | △ | |

- ふしぎ と ふつう はおたがいに効きにくく、ふしぎ同士はよく効く（おばけ同士のイメージ）
- 同じ属性のわざを使うと 1.2 倍（案）

### 6.2 主人公（決定：こおりくんかおにおにを選ぶ）

- 新しく始めるときに、主人公を **こおりくん** か **おにおに** から選んで操作する（決定）
- 選ばなかったほうは、**最初の仲間**になる（決定）
- 主人公は **バトルツリー**（6.4）で強くなる。仲間になったほうは、**バトルツリーでは強くできない**（Lv は上がる）（決定）
- 選んだ主人公は、そのセーブデータのあいだは変えられない（案）。もう一方で遊ぶときは、別のセーブデータで始める

| | こおりくん | おにおに |
|---|---|---|
| タイプ（決定） | **オールラウンダーなアタッカー** | **攻撃と守りに特化したアタッカー** |
| 属性（案） | こおり | ほのお |
| 能力（案） | どの能力もそこそこ。ふつうの攻撃もわざ（特殊）も使える | こうげき・ぼうぎょ・HP が高い。とくこう・すばやさは低め |
| 最初の役職 | アタッカー | アタッカー |

### 6.3 役職（決定：5種類）

キャラにはそれぞれ **役職** がある（決定）。

| 役職 | 得意なこと（決定） | 能力の変わり方（案） | 役職のわざの例（案） |
|---|---|---|---|
| **アタッカー** | 攻撃に特化 | こうげき・とくこう +20%、ぼうぎょ・とくぼう -10% | 強い単体わざ、まとめて攻撃 |
| **ヒーラー** | 回復専門 | とくぼう +20%・HP +10%、こうげき -20% | 仲間の HP 回復、状態異常を治す、部屋全体の回復 |
| **ディフェンダー** | 味方の壁になる | HP +20%・ぼうぎょ・とくぼう +20%、すばやさ -1 段階 | 敵を引きつける（挑発）、仲間をかばう、受けるダメージを減らす |
| **ジャマー** | 敵の妨害が得意 | とくこう +10%・すばやさ +1 段階、こうげき -10% | ねむり・まひ・こんらん・どく、敵を遅くする、ふきとばし |
| **サポーター** | ダンジョン攻略に役立つスキルが多い | 満腹度の減りが少ない、HP -10% | ワナを見つける・道具や階段の場所がわかる・お金が多く拾える・仲間の能力アップ |

- **主人公は役職を切りかえられる**（決定）。切りかえられる役職はバトルツリーで開放する（6.4）
- 役職を切りかえると、**能力もある程度変わる**（決定）。上の表の「能力の変わり方」が今の役職だけにつく（案）
- 切りかえは町の家かギルドでできる。ダンジョンの中では変えられない（案）
- 仲間の役職は決まっていて変わらない（案）。仲間を選ぶときに役職を見て、組み合わせを考える
- 仲間の役職（案）：

  | キャラ | 役職（案） |
  |---|---|
  | こおりくん（仲間のとき） | アタッカー（オールラウンダー） |
  | おにおに（仲間のとき） | アタッカー（攻撃と守り） |
  | やすさん | ヒーラー |
  | たむさん | ジャマー |
  | だけさん | ディフェンダー |
  | 仲間になった敵 | 敵ごとに決める（敵キャラ表に役職の列を足す） |

### 6.4 バトルツリー（決定）

主人公だけが使える、**スキルを開放するしくみ**（決定）。

- **借金を返すと、バトルポイント（BP）がたまる**（決定）。案：1,000 えん返すごとに 1 BP。借金を区切りの額まで返したときは、おまけの BP
- BP を使って、バトルツリーのマスを開放する（決定）：
  - **パラメータが上がる**（HP・こうげき・ぼうぎょ・とくこう・とくぼう・満腹度の最大など）
  - **強いスキルを手に入れる**（わざ・いつも効いている力）
  - **役職を開放する**（開放した役職に切りかえられる）
- 形（案）：まんなかが主人公のマス。そこから 5 つの役職の枝がのびる。となりのマスが開放されていないと、その先は開放できない

  ```
               [アタッカーの枝]
                     │
     [サポーターの枝]─(主人公)─[ヒーラーの枝]
                   ╱      ╲
       [ジャマーの枝]      [ディフェンダーの枝]
  ```

  - 各枝：役職の開放 → 能力アップ → 役職のわざ → 能力アップ → 奥義（その役職でいちばん強いスキル）
  - 枝と枝のあいだに、どの役職でも効く能力アップのマス
  - アタッカーの枝ははじめから開いている（最初の役職）
- こおりくんとおにおにでは、ツリーの中身（わざ・奥義）がちがう（案）。例：こおりくんのアタッカーの奥義は「四天王絶対殺す剣」、おにおにのディフェンダーの奥義は「鬼の仁王立ち」
- 開放した **能力アップ** は、どの役職でも効く。**役職のわざ** は、その役職のときだけ使える（案）
- 町でいつでも見られる。開放はやり直せない（案。あとでやり直しの道具を作るかも）

## 7. わざ（案）

- 覚えられるのは 4 つまで。わざごとに **PP**（使える回数）がある
- 当たる範囲：正面 1 マス / 前方の直線 / 周り 8 マス / 部屋全体
- 効果：ダメージ、状態異常（ねむり・まひ・こんらん・どく）、回復、能力アップ

### こおりくんのわざ（案）

前作の武器をもとにしています。主人公のときは、バトルツリー（6.4）で役職ごとのわざが増えます。

| わざ | 属性 | 範囲 | 内容 |
|---|---|---|---|
| コオリソード | こおり | 正面 | 基本のわざ |
| コオリハンマー | こおり | 正面 | 威力が高い。たまに相手がひるむ |
| こおりのいき | こおり | 直線 | 離れた敵に当たる |
| 四天王絶対殺す剣 | こおり | 周り 8 マス | Lv が上がると覚える。PP が少ない |

### 仲間のわざ（案）

前作の必殺技をそのまま使います。

| キャラ | わざの例 |
|---|---|
| おにおに | 鬼鬼の金棒（ほのお・正面）。主人公のときは、バトルツリーで役職ごとのわざが増える |
| やすさん | やすパンチ（ふつう・正面） |

## 8. 仲間（案）

- ダンジョンに一緒に行けるのは、はじめは **主人公をふくめて 3 人まで**（決定：2026-10-21 ユーザー回答）。**ストーリーが進むと、最大 5 人まで**一緒に冒険できる（決定）
  - 案：ダンジョン 3「ネット寺」をクリアすると 4 人、ダンジョン 5「月の迷宮」をクリアすると 5 人
- 最初の仲間は、主人公に選ばなかったほう（**こおりくんかおにおに**。6.2）
- 仲間は自分で考えて動く。作戦を選べる：「ついてきて」「みんなで戦う」「にげて」
- **仲間を増やす**：
  - やすさん・たむさん・だけさんは、ストーリーで仲間になる
  - ダンジョンの敵を倒すと、まれに「仲間になりたそうにこちらを見ている」（ポケダンと同じ）。町の広場で待っている
- 仲間が倒れても、主人公が無事なら探検は続く。**主人公が倒れたら失敗**
- 仲間の役職（6.3）を見て、アタッカー・ヒーラー・ディフェンダーなどの組み合わせを考える

## 10. 倒れたとき（決定）

ポケダン風にします。
