# 敵キャラ表 ― こおりくんの大冒険～ダンジョンドタバタ大道中～

版: v1.0（2026-10-22。053〜092 の 40 体を決定にして 段階 9 で作った。001〜052 は v0.2 で決定）　[仕様書](spec.md) の 11章のくわしい表です。

- 全部で **約100体** にする予定（決定）。まず **新しい雑魚 52体** を作りました（決定：Claude が考える）
- 名前・見た目・とくちょうは Claude が考えたもので、**このとおりで決定**（2026-10-21 ユーザー回答）
- 前作からのキャラ（ハリー・浦の島重蔵・マキビコンMk-4・奈架多ドラゴン・ゴールド金面犬・四天王・大魔王ASO・ライバル探検隊）は、この表とは別に **ボス・強敵** として出します（末尾の表）
- **絵は [キャラ図鑑 characters.html](characters.html) をダブルクリックすると見られる**（ほかのキャラも全部。053〜092 の案は「元の敵 → 進化形」を並べて、動きつきで表示）
- 残りの約 40 体は、あとで「進化形（強くなった姿）」と追加ダンジョンの敵で埋める予定です → **053〜092 を 9・10 章に書いて 作った**（2026-10-22。ユーザー回答「この案で OK」）
- ドット絵：ハリーの森の 001〜007 は段階 2 で作った（2026-10-21）。ほかは そのダンジョンを作るときに作ります
- 段階 3 で、森の敵のわざを入れた：ムメンキョバチ「つっこみ」・ドングリコ「ころがりタックル」・ネムリダケ「ねむりごな」（ねむり）・ツタンコブ「からみつく」（しばり）・ヨフカシフクロウ「はばたき」（直線。ねむりにならない）。段階 4 で、ペコリスは となりに来ると道具をぬすんで逃げるようにした（たおすと落とす）
