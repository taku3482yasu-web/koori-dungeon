# こおりくんの大冒険～ダンジョンドタバタ大道中～

こおりくんかおにおにを主人公に選んで遊ぶ、ローグライクのダンジョンRPG（ポケモン不思議のダンジョン風）。
素の HTML/CSS/JS で作り、**`index.html` をダブルクリックで遊べます**（ファイルを直接開いても動くように、モジュールではなく順に読むスクリプトにしている）。

## 遊び方（2026-10-23 の追加）

- **ステータス画面**：ダンジョンの「ステータス」ボタン・E キーで、主人公と 仲間の 絵・能力・属性・役職・けいけんち・とくちょう・装備・わざが 見られる
- **装備欄**：キャラごとに 1 つ。ステータス画面で キャラを えらぶか、道具の「装備する」で つける。つけると 持ち物から なくなり、はずすと 持ち物に もどる（いっぱいなら 足元に 置く）。仲間の 能力も 上がる
- **攻撃が 当たる**：壁の中の 敵（壁を通る敵）・水の上の 敵にも、となりからの 攻撃・わざ・投げた 道具が 当たる
- **水の上**：みず・かぜ の 属性の キャラ（主人公・仲間・敵）と 泳げる 敵だけ 通れる。ワープで 水の上に 出なくなった
- **図鑑**：一覧の キャラを 押すと 前の 画面に もどってしまっていた → 一覧の まま その キャラを 上に 出す
- **操作している 仲間が たおれたら**：ターンを 使わずに、次の キャラ（いっしょにいる 生きている キャラ）を 自動で 操作する
- **町に 戻ると 全回復**：HP・状態・PP。広場で 待っている 仲間も
- **広場で ステータス・装備**：仲間を えらんで「ステータス・装備」、主人公は 一覧の いちばん下。町では 装備を はずすと 持ち物へ（いっぱいなら 倉庫へ）
- **直したこと**：仲間を 操作しているときに 主人公が たおれると、町に 戻っても 仲間の 操作の まま・たおれた 主人公が 仲間の 列に 残っていた
- **バトルツリーを のばした**：奥義の 先に 5 マス（能力アップと、どの 役職でも 使える わざ）・いちばん 外に 輪 5 マス
- **わざ 6 つ**：ストーリーを クリアした 主人公は わざを 6 つまで 覚えられる（キーボードの 5・6 も）。仲間は 4 つの まま
- **主人公が たおれても 続く**：生きている キャラが いれば 次の キャラで 続ける。みんな たおれたら 失敗
- テスト：gear.test.js

## 交易所をオンラインにする（Supabase）

**2026-10-22 に設定ずみ**（プロジェクト jknmyakxaketocflgsfs。本物のサーバーで 出品・購入・売上の受け取り・取り下げ・ブラウザからの通信を確かめた）。

ほかのプレイヤーと道具を売り買いするには、出品を置いておく Supabase（無料のサービス）が要ります。設定しなくても遊べます（そのときは コンピューターの探検隊だけ）。

1. https://supabase.com でアカウントを作り、**New project** で新しいプロジェクトを作る（名前は何でもよい。地域は Tokyo がおすすめ）
2. 左のメニューの **SQL Editor** を開き、このリポジトリの `supabase/schema.sql` の中身を全部貼りつけて **Run**
3. 左のメニューの **Project Settings → API** で、**Project URL** と **anon public** の key をコピーする
4. `js/config.js` の `url` と `key` に貼りつける
   ```js
   supabase: { url: 'https://xxxx.supabase.co', key: 'eyJ...' }
   ```
   - anon key は公開してよい鍵です。この鍵でできるのは `schema.sql` の関数（出品を見る・出品・購入・取り下げ・売上の受け取り・引き継ぎの 預ける／受け取る）だけです
   - お金と道具はプレイヤーのブラウザに保存しているので、ずるをしようと思えばできます。気軽な遊びのための しくみです
5. コミットして GitHub に push すると、GitHub Pages の公開ページでもオンラインになります

**引き継ぎ（2026-10-22 追加）**を使うには、`supabase/schema.sql` の いちばん下の「引き継ぎ」の部分（`create table if not exists public.transfers` から 最後まで）を SQL Editor に貼りつけて **Run** してください（全部を貼りつけて Run しても 大丈夫です）。
