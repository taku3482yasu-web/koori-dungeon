# こおりくんの大冒険～ダンジョンドタバタ大道中～

こおりくんかおにおにを主人公に選んで遊ぶ、ローグライクのダンジョンRPG（ポケモン不思議のダンジョン風）。
素の HTML/CSS/JS で作り、**`index.html` をダブルクリックで遊べます**（ファイルを直接開いても動くように、モジュールではなく順に読むスクリプトにしている）。

## 遊び方（段階 7）

- **ダンジョン 7 つ**：ハリーの森（5 階）→ 浦の島の海岸どうくつ（8 階・水たまり）→ ネット寺（10 階・ワナが多い）→ 忍びの屋敷（12 階・すばやい敵）→ 月の迷宮（15 階・しばらくすると階の形が変わる）→ 筋肉の山（18 階・力持ちの敵・溶岩）→ ASOの壺の底（25 階）
- **ボス**：いちばん下の階にいる（ハリー・浦の島重蔵・ダイシ・ズミタニ・ルナヤ・ノゾエマ・大魔王ASO）。たおすまで階段は使えない。たおすと ストーリーが進んで、次のダンジョンが現れる
- **仲間が増える**：やすさん（ヒーラー）・だけさん（ディフェンダー）・たむさん（ジャマー）がストーリーで仲間に。ネット寺をクリアすると 4 人、月の迷宮で 5 人で冒険できる
- **施設は借金を返すと開く**：倉庫 2,000えん・仲間の広場 5,000えん・バトルツリー 10,000えん・鍛冶屋 20,000えん・交易所 30,000えん（返した合計）
- **敵のとくちょう**：壁をすりぬける・水を泳ぐ・分裂・爆発・1 回復活・仲間を回復・仲間を呼ぶ・宝箱や道具に化ける・お金を取る・わざをはね返す など。状態異常に 目つぶし・こおり・やけど・よわき が増えた
- **交易所**：Supabase を設定すると、ほかのプレイヤーの出品を買える・自分の出品がほかのプレイヤーに売れる（下の「交易所をオンラインにする」）

## 遊び方（段階 6 まで）

- タイトル →（はじめから）主人公を **こおりくん**（オールラウンダー）か **おにおに**（攻撃と守り）からえらぶ → はじまりの話 → **町**
- **町**：ダンジョンへ・探検隊ギルド（クエストを受ける・報告）・借金返済所（借金 100,000 えんを返すと BP）・バトルツリー（BP で能力アップ・役職の開放と切りかえ・役職のわざと奥義）・お店・鍛冶屋（敵が落とした素材で武器や道具を作る）・交易所（珍しい道具・ほかの探検隊の出品・自分の出品）・倉庫・仲間の広場（連れていく仲間をえらぶ）・家（セーブ・1 日すすめる）
- ダンジョンを突破・脱出・倒れると町に戻る。倒れると お金と道具の半分をなくし、借金に利子が足される。セーブは自動で、タイトルの「つづきから」で続けられる（ダンジョンの中なら その階のはじめから）
- **役職**：アタッカーから始まり、バトルツリーで開放して切りかえる。役職で能力と、使えるわざが変わる
- **わざ**：4 つまで。PP（使える回数）がある。正面・直線・周り 8 マス・自分 に使うわざがある。Lv が上がると覚え、5 つめは どれかを忘れる
- **属性**：わざの属性と相手の属性で、ダメージが 1.5 倍（ばつぐん）や 0.67 倍（いまひとつ）になる。自分と同じ属性のわざは 1.2 倍
- **状態異常**：ねむり・まひ・こんらん・どく・しばり・ひるみ・大腸炎。ネムリダケ（ねむりごな）やツタンコブ（からみつく）が使ってくる
- **道具**：床に落ちていて、歩くと拾う（24 個まで）。X で道具の画面を開いて、食べる・使う・投げる・置く・つける（装備は 1 つ）。ペコリスは道具をぬすんで逃げる（たおすと落とす）
- **満腹度**：歩くと減り、0 になると HP が減っていく。おにぎりで戻る
- **ワナ**：踏むまで見えない。トゲ・ワープ・大腸炎・ねむり・落とし穴・借金取り（サポーターは見えているワナに気づく）
- **仲間**：主人公にえらばなかったほうが最初の仲間。主人公をふくめて 3 人まで。仲間は自分で考えて動き、役職ごとに動きが変わる（ヒーラーは回復、ディフェンダーは守って敵に ねらわれやすい、ジャマーはねむらせる など）。T（スマホは「作戦」）で作戦を「みんなで戦う・ついてきて・にげて」から選ぶ。歩く先に仲間がいたら入れかわる。けいけんちはみんなに入る
- **仲間を増やす**：たおした敵が ときどき「仲間になりたそうに こちらを見ている」。いっぱいのときは町の広場で待つ。仲間がたおれても探検は続き、主人公がたおれたら失敗
- **お金**：床に落ちている（サポーターは 1.5 倍拾える）。倒れると、お金はすべて・道具は半分なくす。ふっかつのたね・ふるカワのお守りがあれば 1 回だけ復活
- ハリーの森（5 階）で敵と戦いながら、階段で下の階へ降りる。B5F の階段で突破
- ターン制：主人公が 1 回動くと、敵も 1 回動く（ムメンキョバチは 2 回）。敵をたおすとけいけんちが入って Lv が上がる。歩くと HP が少しずつ戻る
- たおれたら、Lv はそのままで B1F からやり直し（町に戻るのは段階 6 から）
- 移動：矢印キー・テンキー（斜めは矢印を2つ同時か、Shift を押しながら）／ダッシュ：B を押しながら移動（敵が見えたら止まる）／向きだけ変える：R を押しながら方向／攻撃・決定：Z・Enter（階段の上なら「降りますか？」）／わざ：1〜4／道具：X／仲間の作戦：T／足ぶみ：Space／戻る：X・Esc／ミニマップ：M
- スマホ：十字ボタン（斜めあり。長押しでダッシュ。敵のほうを押すと向きが変わる）・わざのボタン・攻撃・道具・作戦・足ぶみ・地図
- テスト：`node --test "tests/*.test.js"`（ダンジョンは game.test.js、町は town.test.js、段階 7 は story.test.js）

## 交易所をオンラインにする（Supabase）

ほかのプレイヤーと道具を売り買いするには、出品を置いておく Supabase（無料のサービス）が要ります。設定しなくても遊べます（そのときは コンピューターの探検隊だけ）。

1. https://supabase.com でアカウントを作り、**New project** で新しいプロジェクトを作る（名前は何でもよい。地域は Tokyo がおすすめ）
2. 左のメニューの **SQL Editor** を開き、このリポジトリの `supabase/schema.sql` の中身を全部貼りつけて **Run**
3. 左のメニューの **Project Settings → API** で、**Project URL** と **anon public** の key をコピーする
4. `js/config.js` の `url` と `key` に貼りつける
   ```js
   supabase: { url: 'https://xxxx.supabase.co', key: 'eyJ...' }
   ```
   - anon key は公開してよい鍵です。この鍵でできるのは `schema.sql` の関数（出品を見る・出品・購入・取り下げ・売上の受け取り）だけです
   - お金と道具はプレイヤーのブラウザに保存しているので、ずるをしようと思えばできます。気軽な遊びのための しくみです
5. コミットして GitHub に push すると、GitHub Pages の公開ページでもオンラインになります
