# こおりくんの大冒険～ダンジョンドタバタ大道中～

こおりくんかおにおにを主人公に選んで遊ぶ、ローグライクのダンジョンRPG（ポケモン不思議のダンジョン風）。
素の HTML/CSS/JS で作り、**`index.html` をダブルクリックで遊べます**（ファイルを直接開いても動くように、モジュールではなく順に読むスクリプトにしている）。

## 遊び方（段階 2）

- はじめに主人公を **こおりくん**（オールラウンダー）か **おにおに**（攻撃と守り）からえらぶ
- ハリーの森（5 階）で敵と戦いながら、階段で下の階へ降りる。B5F の階段で突破
- ターン制：主人公が 1 回動くと、敵も 1 回動く（ムメンキョバチは 2 回）。敵をたおすとけいけんちが入って Lv が上がる。歩くと HP が少しずつ戻る
- たおれたら、Lv はそのままで B1F からやり直し（町に戻るのは段階 6 から）
- 移動：矢印キー・テンキー（斜めは矢印を2つ同時か、Shift を押しながら）／ダッシュ：B を押しながら移動（敵が見えたら止まる）／向きだけ変える：R を押しながら方向／攻撃・決定：Z・Enter（階段の上なら「降りますか？」）／足ぶみ：Space／戻る：X・Esc／ミニマップ：M
- スマホ：十字ボタン（斜めあり。長押しでダッシュ。敵のほうを押すと向きが変わる）・攻撃・足ぶみ・地図
- テスト：`node --test "tests/*.test.js"`

## ファイル

| ファイル | 中身 |
|---|---|
| `js/rng.js` | 乱数（種を決めると同じ階になる） |
| `js/dungeon.js` | 階づくり（56 × 32 マス・部屋 4〜8 個）・歩けるか・見える範囲 |
| `js/units.js` | 主人公 2 人・森の敵 7 体の能力、Lv・けいけんち・ダメージの計算 |
| `js/art.js` | ドット絵（こおりくんはスロットと同じ絵・おにおに・森の敵 7 体）・森のマス |
| `js/game.js` | ゲームの進行（主人公の選択・ターン・敵の動き・攻撃・移動・ダッシュ・ミニマップ・階段・暗転）と描画 |
| `js/main.js` | 入力（キーボード・画面のボタン）・「降りますか？」の画面 |
