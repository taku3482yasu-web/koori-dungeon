# こおりくんの大冒険～ダンジョンドタバタ大道中～

こおりくんかおにおにを主人公に選んで遊ぶ、ローグライクのダンジョンRPG（ポケモン不思議のダンジョン風）。
素の HTML/CSS/JS で作り、**`index.html` をダブルクリックで遊べます**（ファイルを直接開いても動くように、モジュールではなく順に読むスクリプトにしている）。

## 遊び方（段階 1）

- ハリーの森（5 階）を歩いて、階段で下の階へ降りる。B5F の階段で突破
- 移動：矢印キー・テンキー（斜めは矢印を2つ同時か、Shift を押しながら）／ダッシュ：B を押しながら移動／足ぶみ：Space／決定：Z・Enter／戻る：X・Esc／ミニマップ：M
- スマホ：十字ボタン（斜めあり。長押しでダッシュ）・決定・足ぶみ・地図
- テスト：`node --test "tests/*.test.js"`

## ファイル

| ファイル | 中身 |
|---|---|
| `js/rng.js` | 乱数（種を決めると同じ階になる） |
| `js/dungeon.js` | 階づくり（56 × 32 マス・部屋 4〜8 個）・歩けるか・見える範囲 |
| `js/art.js` | ドット絵（こおりくんはスロットと同じ絵）・森のマス |
| `js/game.js` | ゲームの進行（移動・ダッシュ・ミニマップ・階段・暗転）と描画 |
| `js/main.js` | 入力（キーボード・画面のボタン）・「降りますか？」の画面 |
